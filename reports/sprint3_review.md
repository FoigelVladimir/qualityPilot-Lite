## Замечания

Подтверждённых P0/P1 в проверенных штатных сценариях не обнаружено.

### P2: неполная проверка структуры CSV отчётов — исправлено

Место: src/qualitypilot/ui/artifacts.py:132, load_reports.

На временной копии COMPLETE run заменён заголовок path на image_path в
patchcore/results.csv. Вместо управляемой ошибки функция выбросила AttributeError:
DataFrame object has no attribute path. AppTest страницы результатов подтвердил
необработанное исключение. Путь/метки сравниваются, но обязательные столбцы
не проверяются до обращения через frame.path.

Исправление: явно проверить необходимые для сравнения и просмотра столбцы,
выдавать ValueError с именем файла и перечнем отсутствующих полей. Использовать
явное обращение по имени столбца. Проверить обязательные поля отображаемых JSON
до рендеринга; не заменять отсутствующие метрики выдуманными числами. Не маскировать
проблему общим except Exception. Добавить регрессионный AppTest повреждённого CSV:
русская ошибка, нет traceback, раздел About доступен.

### P2: синтаксическая ошибка baseline YAML не преобразуется в ошибку интерфейса — исправлено

Место: src/qualitypilot/ui/app.py:84–85 и аналогичная загрузка в results_page.

На временной копии проекта baseline config со строкой data_root: [ вызвал
необработанный yaml.parser.ParserError на странице проверки. AppTest подтвердил
один exception; переход в About работает. Обработчик не включает yaml.YAMLError.

Исправление: преобразовать YAML-ошибку в понятное исключение на границе чтения
конфигурации либо обработать её в местах загрузки UI. Сообщить, какой файл нужно
исправить; сохранить работу остальных разделов. Добавить регрессионную проверку.

### P2: существующий CI не запускает UI-тесты — исправлено

Место: .github/workflows/checks.yml.

Workflow устанавливает только .[dev]; Streamlit отсутствует, поэтому UI-модули
тестов будут пропускаться. Локальный запуск dev/ml/ui их проверяет, но будущий
удалённый CI пока не защищает Sprint 3.

Исходная рекомендация: добавить job с dev/ui без ML extra и запустить UI-тесты
на синтетических фикстурах. Проверять отсутствие пропуска UI из-за missing
Streamlit; реальные модели/датасет для этого job не требуются.
