# Sprint 5 — русский интерфейс и просмотр карт

Работа 22–23 октября 2026; основа — опубликованный commit
`1fabf8e767a2c5d6fa45108b0c39d292aed749e5`, Streamlit 1.50.0.
На момент завершения реализации изменения оставались локально, без commit/push
и нового запуска Actions. Последующая приёмка и подготовка публикации описаны
в [независимом ревью](sprint5_review.md); проверки ниже относятся к реализации.
Это доработка представления, не улучшение ML-качества или локализации.

| Несколько технических изображений без общего сценария осмотра | Оригинал слева, выбранный результат справа; наложение по умолчанию, четыре режима, крупный просмотр |
| Разметка рядом с техническими картами | Отдельный выключенный переключатель разметки только для известной локальной маски |

Сохранены три раздела. Основной путь: выбрать фотографию → превью и кнопка
«Проверить изображение» → рекомендация → осмотр. В настройках по умолчанию
PatchCore и auto; фактическое устройство показано после проверки. Подпись run
содержит дату/время UTC и уникальный суффикс; полное имя и пути — в подробностях.
Временные пороги выключены, исходная рекомендация остаётся видимой, сброс
выключает временную политику. ACCEPT не обещает отсутствие дефекта, score
не представлен вероятностью.

Русские названия метрик, подсказки Precision/Recall/FPR, матрицы ошибок и
расшифровки TP/FP/FN/TN добавлены на страницу результатов. Локализуется копия
таблицы; фильтрация и проверка согласованности работают с исходными полями.
N/A и отсутствие случаев показаны явно. Исторические метрики не зависят от
временных порогов проверки фотографии.

Изменены только UI-модули, тема, UI-тесты и документация. Добавлены небольшие
модули `qualitypilot.ui.presentation` (подписи и копии таблиц) и `style`
(типографика). CSS не подменяет содержимое DOM, JavaScript не внедряется.
API Inspector, CLI, зависимости и форматы артефактов сохранены.

## Карты и состояние

Режимы: «Наложение», «Тепловая карта», «Контур подозрительной области»,
«Бинарная маска». Прозрачность регулируется для наложения. Крупный просмотр
показывает выбранный результат или оригинал на всю ширину; штатный Fullscreen
сохранён. У Isolation Forest — исходник и объяснение отсутствия локализации.
Для upload явно указано, что разметка неизвестна.

Исходная геометрия и anomaly_map не меняются. Маска — строго
`anomaly_map > pixel_threshold`. Контур — её внутренняя граница по четырём
соседям с учётом краёв изображения, нарисованная на копии оригинала NumPy.
Нет очистки маски, удаления компонент, сглаживания или повышения резкости.
Шкала остаётся `0..max(1.5 * pixel_threshold, 1e-6)`, с общей числовой легендой,
без нормирования под максимум фотографии. При историческом пороге карты
8.860112190246582 максимум шкалы — 13.290168285369873.

Загрузка модели ленивая, активен один Inspector на сессию. Только кнопка
проверки вызывает predict. Смена входа/model/run/device сбрасывает результат;
смена model/run/device также сбрасывает временную политику. Отображение,
прозрачность, крупный просмотр, разметка и ручные пороги inference не запускают.
При сокращении имён файлов обнаружена и исправлена проблема одинаковых
`000.png` в разных типах дефекта: контекст списка теперь сбрасывает прежний путь.
Есть регрессия, проверяющая фактически выбранный полный путь.

Сохранены upload в памяти, JPG/PNG с проверкой реального формата, лимиты
10 MiB / 20 млн пикселей, обработка missing artifacts и недоступной CUDA.
Валидация CSV/JSON до рендеринга и преобразование синтаксической ошибки YAML
не ослаблены; прежние регрессии повреждённых файлов продолжают выполняться.

## Браузер и читаемость

Проверено приложение из корневых обновлённых исходников, а не прежней delivery-copy.
Собственные старые серверы остановлены, посторонние процессы не затрагивались.
После возобновления работы 23 октября корневой сервер снова запущен:
`python -m streamlit run app.py --server.port 8501`, localhost only.

В браузере пройдены normal/defective, обе модели, PNG/JPG и повреждённый upload,
четыре режима карт, alpha 0.45→0.50, крупный просмотр, включение локальной разметки,
временный reject=30 (REVIEW при сохранённом REJECT), reset, сохранённые отчёты
с русскими таблицами и матрицами. Полный цикл и счётчики дополнительно проверены
реальным AppTest. Для проверки ошибок использованы отдельные копии отчётов:
CSV без обязательных столбцов, JSON без обязательных полей, синтаксически
повреждённый baseline YAML. Появлялась русская ошибка с файлом/причиной без
traceback; переходы в другие разделы доступны. Копии после проверки восстановлены.

Проверены CSS-окна 1366×768 и 1100×768 при масштабе 100%. Для 200% пользователь
явно согласовал эквивалентную компоновку: 683×384 и 550×384. Встроенный браузер
не изменил нативный zoom по Ctrl+Plus/Equal, поэтому нативный zoom 200% не заявлен
проверенным. При узких размерах колонки переходят в вертикальный поток,
sidebar сворачивается, доступна вертикальная прокрутка. Ширина документа равна
ширине окна: 1366/1100/683/550; горизонтального переполнения страницы не найдено.
Широкие таблицы сохраняют собственную прокрутку. Временные размеры окна сброшены.

Проверены computed styles и фон, включая прозрачность предков. В процессе
проверки обнаружена стандартная opacity 0.6 контейнера caption; исправлена на 1,
после чего UI-тесты и браузерный замер повторены. Основной текст 16 px,
подписи фотографий 14 px. Подписи #334c5e на #f7f9fb: **8.52:1**;
белый текст основной кнопки на #147d73: **4.99:1** в обычном состоянии.
В сохранённой итоговой выборке основного/вспомогательного текста минимум 7.77:1
(кнопка в момент замера была в более тёмном активном состоянии).
Системная иконка сворачивания sidebar имеет 3.85:1 и не является обычным текстом.
Статусы различимы значком, текстом и кодом. Это выборочная проверка читаемости,
не полная WCAG-сертификация; ранний замер без учёта opacity не используется
как подтверждение соответствия.
