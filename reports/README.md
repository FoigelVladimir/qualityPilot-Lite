# Отчёты

Фактические эксперименты пишутся в `runs/<experiment>/` и исключены из Git,
поскольку могут содержать изображения MVTec AD. Первый реальный baseline
запущен 21 октября 2026 на bottle из публичной сторонней копии Hugging Face.
Краткий отчёт без изображений: [bottle-baseline.md](bottle-baseline.md).
Полные локальные метрики: `runs/bottle-baseline/metrics.json`.

Спринт 2: [preflight](sprint2_preflight.md), [итоговый отчёт](sprint2_report.md).
Полный успешный запуск: `runs/bottle-patchcore-20261021T103450Z-5eddf169/`.
Неудачный setup-запуск сохранён отдельно; он описан в отчёте.


Спринт 3: [интерфейс](sprint3_report.md), [независимое ревью и исправления](sprint3_review.md).
Спринт 4: [чистые установки, полный повтор и готовность поставки](sprint4_report.md).
Спринт 5: [русский интерфейс и просмотр карт](sprint5_report.md),
[независимое ревью](sprint5_review.md).
После ревью: [исправления UI и оформление портфолио](portfolio_report.md).

и график метрик. [Обзор проекта](../README.md).
