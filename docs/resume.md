# QualityPilot Lite — формулировка для резюме

Разработал учебный ML/CV-проект для обнаружения визуальных дефектов изделий:
baseline Isolation Forest на глобальных признаках и интеграция PatchCore через
Anomalib. Сравнил методы на MVTec AD bottle с фиксированным split и normal-only
калибровкой, обеспечил воспроизводимость через manifest, lock и тесты. Реализовал
Streamlit-интерфейс с heatmap, маской, ACCEPT/REVIEW/REJECT и просмотром отчётов.

Подтверждённый результат на 83 известных test-изображениях: image AUROC
0.6246 у baseline и 1.0 у PatchCore; у PatchCore остаются 4 FP при фиксированном
пороге и умеренная локализация (Dice 0.5604). Это учебный результат на одной
категории, без гарантии качества на новых данных и промышленного внедрения.
Алгоритм PatchCore реализован Anomalib; собственный код отвечает за pipeline,
интеграцию, калибровку, оценку и интерфейс.
